## Findings

- **Sysmon Event 10 gap confirmed.** WS01's Sysmon config has no ProcessAccess
  rules, so nothing is logged when a process opens `lsass.exe`. There was no
  Event 10 before the attack or during a completed dump. The textbook LSASS
  detection has no data here.
- **Defender blocks the attack before it starts.** Atomic T1003.001 test 2 was
  blocked as `Trojan:Win32/RundllLolBin.AF` on the command line of the
  PowerShell wrapper, so `rundll32.exe` never ran. Neither Kibana nor WS01's
  local Sysmon log had an Event 1 for it. Defender's log is the only record of
  a blocked attempt, and the Event 1 rule cannot see one.
- **With real-time protection off, the dump completes** and Sysmon Event 1
  (`rundll32.exe` with the comsvcs `MiniDump` command line, parent
  `powershell.exe`) and Event 11 (the `.dmp` file) both fire.
